# Job Portal

Это веб-приложение для поиска работы и откликов на вакансии, а также для создания и редактирования резюме. Проект использует Django для создания серверной части, а также включает функциональность для пользователей, работодателей и администраторов.

### Технологии

* Django (Backend)
* Python 3
* PostgreSQL (База данных)
* HTML, CSS, JavaScript (Frontend)
* FastAPI (для отдельных микросервисов)

### Установка и настройка

#### Требования

* Python 3.x
* PostgreSQL
* Git

#### Шаги для запуска

1. Клонируйте репозиторий:

`git clone https://github.com/atytaev/job_portal.git`

`cd job_portal`
2. Создайте и активируйте виртуальное окружение:

`python -m venv .venv`

`source .venv/bin/activate  # Для Linux/macOS`

`.venv\Scripts\activate  # Для Windows`

3. Установите зависимости:

`pip install -r requirements.txt`

4. Настройте базу данных в settings.py, указав правильные параметры подключения к PostgreSQL.

5. Примените миграции для создания базы данных:

`python manage.py migrate`

6. Создайте суперпользователя для админки:

`python manage.py createsuperuser`

7. Запустите сервер:

`python manage.py runserver`

Теперь приложение доступно по адресу: http://127.0.0.1:8000.

### Основные функции

#### Для пользователя:

* Регистрация и аутентификация.
* Создание и редактирование резюме.
* Отклик на вакансии.
* Просмотр вакансий и фильтрация по различным параметрам.

#### Для работодателя:

* Размещение вакансий.
* Просмотр откликов на вакансии.
* Утверждение откликов и управление процессом найма.

#### Пример использования

1. Для регистрации создайте аккаунт через страницу регистрации.
2. После авторизации вы можете создать свое резюме, а затем откликнуться на вакансии.
3. Работодатель может разместить вакансии, просматривать отклики и управлять кандидатами.
